# 💡 Bulb ON/OFF Using JavaScript

A simple JavaScript project that demonstrates how to control a light bulb's ON and OFF states using DOM manipulation and event handling.

## 📖 Project Overview

This beginner-friendly project allows users to turn a virtual light bulb ON and OFF by clicking buttons. It is designed to help learners understand the basics of JavaScript and how it interacts with HTML elements.

## ✨ Features

- Turn the bulb ON
- Turn the bulb OFF
- Interactive user interface
- Dynamic image switching using JavaScript
- Simple and beginner-friendly implementation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```text
BULB-ON-OFF-USING-JAVASCRIPT/

```

## ⚙️ How It Works

1. The webpage displays a bulb image and control buttons.
2. When the user clicks the ON button, JavaScript changes the bulb image to the illuminated version.
3. When the user clicks the OFF button, JavaScript changes the bulb image back to the non-illuminated version.
4. This interaction is achieved through DOM manipulation and event handling.
